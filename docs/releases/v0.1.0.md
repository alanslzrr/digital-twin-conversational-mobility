## Resumen

Primera versión reutilizable de la evaluación de mobai: conversar sobre la movilidad de Madrid, consultar herramientas con procedencia temporal y explorar los datos del núcleo desde un panel privado. La entrega permite instalar el código localmente; no publica un servicio de movilidad ni datos de operadores.

## Capacidades y correcciones

- Chat oficial EVE con sesiones durables, idioma ES/EN, acceso Better Auth y listado de conversaciones propias.
- Dieciséis herramientas MCP implementadas para rutas, transporte, avisos, contexto urbano e histórico; proveedores y almacenamiento aislados en Mobility Core.
- OpenTripPlanner para routing, con procedimientos separados de preparación, activación y rollback de datos/grafo.
- Panel privado para catálogos, observaciones, fuentes, consultas, actividad y telemetría conversacional propia.
- Presentación del proyecto con demo y capturas reales; guías de instalación, uso y operación.
- Proceso de contribución por issue y PR, controles de metadatos y decisión de release; canal privado de reportes de seguridad.

Consulta los contratos exactos en la [referencia MCP](../reference/mcp.md) y las condiciones de cada producto en el [registro de fuentes](../sources/README.md).

## Seguridad

La entrega conserva autorización por propietario, origen exacto, cookies protegidas, herramientas EVE por defecto deshabilitadas y límites de generación. La firma JWT usa HS256 con secreto mínimo de 32 bytes; Better Auth utiliza scrypt con sal aleatoria para contraseñas.

Las correcciones de dependencias incluyen:

- sharp 0.35.5 / librsvg: GHSA-wq5f-xc86-pv6w.
- source-map-js 1.2.2: GHSA-68fv-2mgg-jv7q.
- KaTeX 0.18.2: GHSA-238p-pmpm-9mq7.
- Undici fijado a versiones corregidas; CLI Vercel retirada por una dependencia sin parche. Véanse los [overrides](../../pnpm-workspace.yaml) y la [política de seguridad](../../SECURITY.md).

No se atribuyen estas vulnerabilidades al código propio. La auditoría actual no identificó una vulnerabilidad propia publicada pendiente; no es una garantía de ausencia de fallos.

## Compatibilidad y actualización

- Node 24.21.0 o superior dentro de la rama 24; pnpm 10.30.3; dependencias fijadas en el lockfile.
- Los paquetes del monorepo siguen privados: no se publica un paquete npm.
- Sigue la [instalación](../installation.md) para un entorno nuevo. Para un entorno existente, conserva una copia de la base de datos y configuración privada; aplica las migraciones incluidas mediante `pnpm db:migrate` antes de usar el código de esta entrega.
- La versión inicial establece la base; no promete compatibilidad estable 1.0. Los siguientes cambios de contrato/esquema deben indicar su migración y rollback.
- El tag de código no sustituye la versión del grafo de routing ni restaura datos locales.

El historial de ejecución está disponible en [GitHub Actions](https://github.com/alanslzrr/digital-twin-conversational-mobility/actions/workflows/ci.yml).

No se ejecutan nuevas inferencias, consultas de proveedores ni benchmarks de routing para esta entrega. Las pruebas de infraestructura omitidas localmente se distinguen de las ejecutadas en CI. El escaneo de secretos no hace OCR de las capturas ni demuestra ausencia universal de formatos no reconocidos.

## Limitaciones y pendientes

- Evaluación autenticada y local; sin despliegue cloud ni servicio público.
- Fuentes con cobertura y frescura distintas: no interpretar histórico o publicaciones estáticas como observaciones en vivo.
- No se registra como implementada ninguna herramienta ausente ni se fabrican rutas.
- El servicio bootstrap no equivale a un servidor OAuth completo. Rotación de claves y arquitectura cloud requieren decisiones posteriores.
- Cobertura de ramas no medida y análisis dinámico dedicado no ejecutado; no se declaran como cumplidos por la existencia de tests.
