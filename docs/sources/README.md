# Índice de fuentes y alcance R1

[Índice de la wiki](../index.md) · [Registro de fuentes](README.md) · [Recursos y altas](../resources/index.md) · [Referencia MCP](../reference/mcp.md)

Fuentes utilizadas por el proyecto, con su cobertura, acceso, atribución y condiciones de reutilización. Revisión: **02/10/2026**. El uso de evaluación es no comercial; cada producto conserva sus condiciones específicas.

El sistema distingue la frecuencia de publicación del proveedor, el intervalo de adquisición local y la antigüedad del dato. Las adquisiciones respetan la ventana de actividad, las leases y el backoff. ## Evidencia de revisión y límites aceptados

Las referencias de BiciMAD, DGT y CRTM se contrastaron el 02/10/2026. La página de condiciones EMT devolvió primero un error 503 y después redirigió a login; se conserva su revisión anterior. Las condiciones de cada producto figuran en la tabla.

`license_reviewed_at` se rellena automáticamente al activar fuentes o importar Renfe. Para conocer cuándo se revisaron las condiciones, utiliza las fechas de este registro y sus referencias. La [guía de cuentas y claves](../resources/accounts.md) explica el acceso y la renovación de credenciales.

La cobertura RT y de accesibilidad de esta versión incluye estimaciones y avisos Renfe, llegadas y avisos EMT, y declaraciones estáticas de paradas y vehículos. Las ampliaciones excluidas se recogen en el [roadmap](../roadmap.md).
